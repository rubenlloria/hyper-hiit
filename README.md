  # HYPER//HIIT
**Tactical Performance Interface**

HYPER//HIIT is a free, highly configurable open-source software suite designed for HIIT protocol execution and performance tracking. Built to monitor and log your progression through custom tactical training milestones.

## Technical Specifications
- **Framework:** Qt 6 / QML
- **Architecture:** C++ Backend for logic / Tactical UI in QML.
- **System Design:** Modular components (`NeonAccordion`, `CyberButton`) with dynamic theme management.
- **Build System:** CMake

## Project Structure
- `master`: Stable production branch.
- `devel`: Active integration and rapid prototyping.

## Documentation & Guidelines
Please refer to the `guidelines/` folder for architectural principles and design standards.
