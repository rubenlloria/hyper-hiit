## El catálogo de prefijos estándar:
- **feat:** Una nueva funcionalidad (Feature).
- **fix:** Corrección de un error (Bug fix).
- **docs:** Cambios en la documentación (README, comentarios en el código, etc.).
- **style:** Cambios de formato que no afectan el funcionamiento (espacios en blanco, indentación, puntos y coma).
- **refactor:** Reestructuración del código que no añade funcionalidades ni arregla bugs (ej: limpiar una función).
- **test:** Añadir o corregir pruebas unitarias.
- **chore:** Tareas administrativas, configuración de herramientas, cambios de nombres de archivos (como lo que acabamos de hacer), o actualizaciones de dependencias que no tocan el código.
